Git Ödevi

Bu projede Git, VS code ve GitHub kullanarak ödev teslim sürecini gerçekleştirdim.

Kullanılan Git Komutları
git add . → Dosyaları commit için hazırlamak için kullandım.
git commit -m "..." → Yaptığım değişiklikleri kaydetmek için kullandım.
.gitignore → Git tarafından takip edilmesini istemediğim dosyaları belirtmek için kullandım.
git status → Dosyaların mevcut durumunu kontrol etmek için kullandım.
git log → Daha önce yapılan commitleri görüntülemek için kullandım.
git switch → Branch değiştirmek için kullandım.
git merge → Branch'leri birleştirmek için kullandım.
Ödev Teslimi

Ödevimi Git ve VS Code kullanarak versiyon kontrolü altında geliştirdim ve tamamladıktan sonra GitHub üzerinden teslim ettim.

Bu ödev sayesinde temel Git komutlarını ve branch işlemlerini uygulamalı olarak öğrenmiş oldum.
